=== review contract
The contract of the REVIEW step still applies: write the proven findings to .git/agent-review.md, fix them, update .git/agent-checklist.json, run only the build and tests relevant to your fix (cargo test -p <crate> <filter>; the full verify passed before the review and root runs it again afterwards), then commit with the message "Apply review findings".
